【V3.2.2 更新内容】

1. 修复 nano-banana-2 / nano-banana-pro 高清出图问题
   - 修复了选择 2K / 4K 质量时实际仅生成 1K 图片的 bug
   - 原因：请求未把分辨率参数传给 Gemini 接口
   - 现在 2K / 4K 会按选择的实际分辨率生成

【安装说明】

Windows 用户：
  直接运行 GlacierAI_V3.2.2.exe，无需安装

首次使用：
  1. 启动程序后进入登录页面
  2. 输入从 hfsyapi.cn 获取的 API Key
  3. 点击「不知道如何获取?」可查看详细教程

【主要功能】

✓ 图片生成 (gpt-image-2 / gpt-image-2pro / nano-banana-2 / nano-banana-pro)
✓ 视频生成 (sora-2 / sd-2 / sd-2-vip / Kling Omni)
✓ 图生图（支持参考图上传）
✓ 历史记录持久保存
✓ 多任务并发与排队（可设置 1-5 并发）
✓ 余额实时查询
✓ 自动重试机制（502/503 错误）
✓ 界面亮度/字体大小自定义
✓ API Key 本地安全保存
