GlacierAI V3.0 更新说明
=======================

发布日期：2026-06-08


新增功能
--------

1. API Key 本地保存（免重复输入）
   - 登录页新增「记住 API Key」勾选项，默认勾选
   - 勾选后下次启动时登录页会自动填入上次保存的 Key，回车即可进入
   - Key 保存在程序同目录下的 api_key.dat（base64 编码，仅防直接窥视，建议本机使用）
   - 不勾选则照常每次输入；不勾选时也会清除已保存的 Key

2. 账户余额显示
   - 左侧导航栏底部新增余额面板，启动时自动加载
   - 每次图片 / 视频生成完成后自动刷新
   - 旁边「⟳」按钮可手动刷新
   - 数据来源：hfsyapi 余额查询接口，与后台数值一致

3. 切换账号
   - 侧边栏底部新增「切换账号」入口
   - 点击后返回登录页，可在输入框里改成另一个 API Key（不会清除已保存的 Key）
   - 想彻底清除已保存的 Key：在登录页取消「记住 API Key」勾选后回车即可

4. 新增 Gemini-3-Pro-Image-Preview 图片模型（继承自 V2.9.1）
   - 别名 nano banana pro，Google 旗舰级推理式图像生成 / 编辑模型
   - 支持文生图、图生图，主打"先理解、再生成"
   - 4K 画质、精准文字渲染、强对话编辑
   - 支持比例：1:1、4:3、3:4、16:9、9:16
   - 支持画质：1K / 2K / 4K，参考图最多 4 张
   - 用法：图片生成页选择模型为 gemini-3-pro-image-preview，比例选项会自动切换


兼容性
------

- 历史记录、UI 设置等数据格式无变化，可直接覆盖升级
- 旧版用户升级 V3.0 后首次启动仍会显示登录页，勾选「记住」并回车即可保存 Key
- 已保存的 Key 文件路径：程序同目录下的 api_key.dat


安全提示
--------

- api_key.dat 仅做 base64 编码，不是加密；请勿把整个程序目录拷贝给他人
- 共享电脑上建议不勾选「记住 API Key」
- 若 Key 泄露，请到 hfsyapi 后台重新生成
