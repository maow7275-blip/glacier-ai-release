【V3.3 更新内容】

一、图片模型更新

1. 下线 gemini-3-pro-image-preview 模型
2. 新增 nano-banana-2（轻量快速，适合高频次创作）
3. 新增 nano-banana-pro（旗舰画质，商业级创作首选）
   - 两款模型均支持文生图 / 图生图，最多 7 张参考图
   - 支持分辨率：1K / 2K / 4K
   - 修复选择 2K / 4K 时实际仅生成 1K 的问题
4. 比例扩充为 13 种（nano-banana 系列）
   - 1:1、2:1、1:2、3:2、2:3、4:3、3:4、5:4、4:5、
     16:9、9:16、21:9、9:21
   - 切换到 nano-banana 系列后，比例下拉自动切换

───────────────────────────────────────────────────────

二、视频模型更新

1. 新增 sd-2-fast 模型
   - 时长 5–10 秒，提示词上限 5000 字
   - 支持最多 9 张参考图，单图 ≤30MB，总和 ≤270MB
   - 支持参考视频（3 条，单段 2–10s、≤50MB，总时长 ≤10s）
   - 支持参考音频

2. 新增 sd-2-vip-720 模型
   - 参数与 sd-2-vip 一致，专业级视频生成
   - 时长 5–15 秒，提示词上限 10000 字

3. sd-2-vip 时长范围修正
   - 从原来的 4–16 秒改为 5–15 秒（与接口文档一致）

4. 视频比例可选（sd-2 / sd-2-fast / sd-2-vip / sd-2-vip-720）
   - 新增"视频比例"下拉框，选择上述模型时显示
   - 可选：自动 / 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16
   - 选"自动"由服务端根据横竖屏推导

5. Kling Omni 替换为 kling-o3
   - 时长：5–15 秒任意整数（原来是 3/5/8/10/12/15 离散）
   - 提示词上限：1500 → 5000 字
   - 图片参考：最多 8 张（原来 7 张，带视频降为 4 张）
   - 不再支持参考视频 / 参考音频 / 首尾帧
   - 横屏 / 竖屏 / 方屏可选

【安装说明】

Windows 用户：
  直接运行 GlacierAI_V3.3.exe，无需安装

首次使用：
  1. 启动程序后进入登录页面
  2. 输入从 hfsyapi.cn 获取的 API Key
  3. 点击「不知道如何获取?」可查看详细教程
