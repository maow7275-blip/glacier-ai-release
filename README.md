# Glacier AI

基于 hfsyapi.cn 的图片 / 视频生成桌面工具。

## 下载

- **macOS**：[GlacierAI_3.0.0_mac.dmg](https://github.com/maow7275-blip/glacier-ai-release/releases/download/v3.0.0/GlacierAI_3.0.0_mac.dmg) （首次打开请参考 dmg 内的 *首次使用必读.txt*）
- **Windows**：见 [Releases 页](https://github.com/maow7275-blip/glacier-ai-release/releases) 上的 `GlacierAI_V3.0.exe`

## 功能

- 图片生成：gpt-image-2 / gpt-image-2pro / Gemini-3-Pro-Image-Preview
- 视频生成：sora-2 / sd-2 / sd-2-vip / Kling Omni
- 历史记录、参考图上传、批量保存
- API Key 本地保存（可选）+ 账户余额实时显示
- 字体大小、亮度自定义

## 使用

1. 下载对应平台的安装包并打开
2. 登录页输入 hfsyapi.cn 的 API Key（勾选「记住」可下次免输）
3. 进入主界面即可生成图片 / 视频
