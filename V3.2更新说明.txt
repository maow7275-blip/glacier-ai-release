GlacierAI V3.2 更新说明
========================

发布时间：2026-06-15

本次重点：多任务并发与排队
------------------------

V3.1 之前一次只能生成一个任务（多张图是单任务内部并发），跑视频时需要等完才能再点。V3.2 重构为
"任务级并发 + 排队"模型：

【新增能力】

1. 多任务并发
   - 图片任务、视频任务共享一个全局并发额度（默认 3 个）。
   - 在「设置」里有"并发任务数"下拉（1-5），保存到 ui_settings.json。
   - 点"生成图片/生成视频"不再禁用按钮，可连续提交，超出并发的任务自动进入排队。

2. 任务排队
   - 队列无上限 （含正在跑 + 等待中）
   - 底部状态栏始终显示「图片 X 跑 · 视频 Y 跑 · 排队 Z / 上限 N」。

3. 任务卡片（TaskCard）
   - 每个任务显示为一张卡片：标题、状态徽章（排队中 / 生成中 / 已完成 / 失败）、进度、缩略图网格、操作按钮。
   - 图片 tab 只显示图片任务，视频 tab 只显示视频任务（互不干扰）。

4. 任务取消
   - 等待中任务：点 ✕ 直接从队列移除。
   - 生成中任务：点 ✕ 弹"已在生成无法取消"。

5. 失败任务
   - 红色"失败"徽章 + 错误原因 + "重试"按钮（重新入队）。

6. 关闭程序保护
   - 有未完成任务时弹「还有 X 个任务未完成，确认关闭？」。

7. 切换账号保护
   - 队列非空时拦截切换，提示先取消或等待完成。

8. 历史记录改造
   - 按 task 粒度保存，文件名带 task_id 后缀避免并发撞名。
   - 失败任务也进历史，记录 status / error 字段（旧记录依然可读）。

9. 余额刷新
   - 每个任务完成都会刷一次（不再是全部完成才刷）。

【保持不变】

- 单任务内部仍然并发请求 N 张图，张数上限不变（图片 1-10，视频 1-5）。
- 任务卡片缩略图大小不变（150x150）。
- 历史记录的视频缩略图和清空逻辑保持兼容。
- API Key、参考图、首尾帧、字体大小、亮度、主题、登录页等其他模块未改。

【兼容性】

- 旧的 ui_settings.json 没有 concurrency 字段，启动时默认填 3。
- 旧的 history.json 不带 task_id，仍然能正常显示。
